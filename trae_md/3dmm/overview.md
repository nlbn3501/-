# 3D思维导图 (3dmm) - 总览

## 一、功能定位

3D思维导图是知识点的空间化目录视图，以球体节点和曲线连线呈现树形层级结构。用户通过轨道相机浏览、选择、编辑知识点。

支持**多星系布局**：根星系以原点为中心按同心球面分布，每个自由节点拥有独立的星系，在根星系外层轨道球上分布。

## 二、模块组成

| 模块 | 文件 | 职责 |
|------|------|------|
| KnowledgeMap | KnowledgeMap.gd | 主控制器：相机、交互、对话框、快捷键 |
| PointManager | PointManager.gd | 3D节点渲染：球体、标签、连线、材质 |
| LayoutManager | LayoutManager.gd | 布局算法：多星系布局、同心球面、自适应半径 |
| ContextMenuManager | ContextMenuManager.gd | 右键菜单 |
| HistoryManager | HistoryManager.gd | 撤销/重做 |
| DataManager | DataManager.gd | 数据读写（共享） |

## 四、与2D思维导图的关键差异

| 维度 | 2D思维导图 | 3D思维导图 |
|------|-----------|-----------|
| 布局 | XMind左右展开 + 手动拖拽 | 同心球面（自动），多星系 |
| 拖拽 | 允许（子树整体拖拽/吸附/拖出） | 禁用（由布局算法控制） |
| 节点形态 | 卡片（白框透明填充白字） | 球体 |
| 连线 | Line2D贝塞尔曲线 | TubeTrailMesh曲线 |
| 坐标系 | 2D (pos2d) | 3D (position) |
| 缩放 | container.scale | 相机半径 |
| 选中/悬停 | 边框颜色变化 | 辉光效果 |
| 快捷键 | Tab（子节点/自由节点） | Tab（新增子节点） |
| 星系 | 星系节点通过树形结构 + 子树整体拖拽管理 | 星系通过同心球面布局 + 轨道球分布 |

## 五、已知需微调项

> 以下为基于现有实现需要确保正确的行为定义

1. **拖拽结束必须保存**：拖拽结束后调用 `history_manager.push_move_action()` + `data_manager.save_data()`
2. **新建后聚焦+选中**：`_do_create_node()` 结尾调用 `focus_and_select_node(new_index)`
3. **删除后清理关系**：删除节点时，子节点的 `parent` 字段需清空
4. **多选批量操作**：Ctrl+左键添加/移除选中，Delete批量删除
5. **相机聚焦不卡死**：聚焦目标在手动旋转时自动清除
6. **星系迁移后自动布局**：吸附/拖出操作后调用 `apply_layout()` 重新渲染
