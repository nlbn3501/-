# 3D思维导图 - 节点交互

## 一、选择系统

### 1.1 单选

| 触发 | 行为 |
|------|------|
| 左键点击节点 | 清除旧选择 → 选中该节点 → 高亮 → `selected_index = idx` |
| 左键点击空白 | 清除所有选择 |

### 1.2 多选

| 触发 | 行为 |
|------|------|
| Ctrl + 左键点击节点 | 切换该节点的选中状态（添加/移除） |
| Ctrl + 左键点击空白 | 无操作 |

### 1.3 选择状态

| 变量 | 类型 | 说明 |
|------|------|------|
| `selected_index` | int | 最近选中的单个节点索引，-1表示无选中 |
| `selected_indices` | Array[int] | 所有选中的节点索引列表 |

## 二、拖拽系统

3D思维导图**不支持节点手动拖拽**，节点位置由布局算法自动计算。

### 2.1 保留选择功能

- 左键仍可选择/多选节点
- 双击弹出详情
- 右键弹出菜单

### 2.2 正确行为验证点

1. 节点位置始终由布局引擎决定
2. 星系合并/拖出后自动重新布局

## 三、右键菜单

### 3.1 节点菜单

| 菜单项 | 行为 |
|--------|------|
| 查看详情: {name} | 弹出详情弹窗 |
| 定位到该节点 | 聚焦+选中 |
| 在2D视图中打开 | 切换到2D视图 |
| --- | 分隔线 |
| 标记为已掌握 | mastery=2, 保存, 刷新 |
| 标记为学习中 | mastery=1, 保存, 刷新 |
| 标记为未学习 | mastery=0, 保存, 刷新 |
| --- | 分隔线 |
| 编辑节点 | 弹出编辑对话框 |
| 删除节点 | 弹出确认对话框 |

### 3.2 空白菜单

| 菜单项 | 行为 |
|--------|------|
| 新建节点 | 弹出新建对话框（位置=鼠标射线与平面交点） |
| --- | 分隔线 |
| 自动布局 | 重新应用布局算法（多星系布局） |
| 刷新 (R) | 重新加载数据并渲染 |
| 重置视图 | 相机回到默认位置 |
| 截图 | 保存当前视口为PNG |
| 材质调试面板 | 打开/关闭材质参数面板 |

### 3.3 多选菜单

| 菜单项 | 行为 |
|--------|------|
| 批量标记为已掌握 | 所有选中节点mastery=2 |
| 批量标记为学习中 | 所有选中节点mastery=1 |
| 批量标记为未学习 | 所有选中节点mastery=0 |
| 批量删除 | 删除所有选中节点 |

## 四、对话框

### 4.1 新建节点对话框

| 字段 | 控件 | 默认值 |
|------|------|--------|
| 名称 | LineEdit | 空（必填） |
| 描述 | TextEdit | 空 |
| X/Y/Z | LineEdit × 3 | 鼠标位置或(0,0,0) |
| 掌握度 | SpinBox (0-2) | 0 |
| 父节点 | OptionButton | 根据右键上下文预选 |
| 所属星系 | Label（只读） | 继承父节点galaxy_id或新建（新增） |

确认后：
1. 生成唯一名称和ID
2. 继承父节点的 `galaxy_id`（无父节点则创建唯一新ID）
3. 添加到DataManager
4. 推入HistoryManager
5. 保存数据
6. rebuild_all()
7. focus_and_select_node(new_index)

### 4.2 编辑节点对话框

与新建相同，但预填当前值（包括 `galaxy_id`）。确认后：
1. 更新DataManager
2. 推入HistoryManager
3. 保存数据
4. update_single_point(index)
5. focus_and_select_node(index)

### 4.3 删除确认对话框

显示节点名称，确认后：
1. 推入HistoryManager
2. 从DataManager删除
3. 清理子节点的parent字段
4. 清理该星系（如果为空则回收galaxy_id）
5. 保存数据
6. rebuild_all()

## 五、详情弹窗

双击节点或右键→查看详情时弹出，显示：
- 名称
- ID
- 描述
- 父节点
- 掌握程度
- 位置（pos2d）
- 路径（从星系根节点到当前节点的完整路径）
- 子节点数
