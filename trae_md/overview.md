# 考研知识图谱 - 总体架构需求文档

## 一、产品定位

考研学习辅助软件，以知识图谱为核心，帮助用户管理和复习考研知识点。
核心技术：Godot 引擎，3个视图（3D 思维导图 + 2D 思维导图 + 2D 认知地图）。

## 二、核心架构

```
启动 → 主界面（学科文件管理）
        │
        └── 打开学科文件 → 编辑界面（Tab切换3个核心功能）
                              ├── 3D 思维导图 (3dmm) — 空间化知识目录
                              ├── 2D 思维导图 (2dmm) — XMind风格手动编辑
                              └── 2D 认知地图 (2dtr) — 解题标注与关系网
```

## 三、3个视图对比

| 维度 | 3D思维导图 (3dmm) | 2D思维导图 (2dmm) | 2D认知地图 (2dtr) |
|------|-------------------|-------------------|-------------------|
| 核心用途 | 空间化知识目录 | 目录编辑与管理 | 解题经验编织 |
| 节点内容 | 知识点（球体） | 知识点（卡片） | 知识点(只读) + 题目(用户创建) |
| 关系类型 | 仅父子 | 仅父子 | 5种关系（用到/可替换/前置/延伸/自定义） |
| 布局方式 | 自动同心球面 | XMind左右展开+手动拖拽 | 力导向自动布局 + 用户pinning |
| 拖拽行为 | 不支持 | 子树拖拽/吸附/拖出 | 只拖拽位置（固定后不再受力） |
| 编辑范围 | 不可编辑 | 节点CRUD | 题目CRUD + 关系编辑 |
| 用户场景 | 梳理考纲、复习大纲 | 构建知识点树 | 刷题时标注题目↔知识点关联 |

## 四、核心模型

**思维导图** = 知识目录（有什么知识点，归在哪个章节目录下）
**认知地图** = 解题经验网（题目拆解了哪些知识点，它们之间有什么关系）

一句话本质：一个题目 = 一套关系包，知识点是复用的原子单位。

### 认知地图与思维导图的关系

独立但不割裂：

| 维度 | 思维导图 | 认知地图 |
|------|---------|---------|
| 管理内容 | 知识点（原子单位） | 题目 + 关系 |
| 节点类型 | 只有知识点 | 知识点（只读引用）+ 题目（创建） |
| 增删节点 | ✅ | ❌ 不增删知识点，只增删题目 |
| 关系类型 | 只有 parent | 5种关系 + 自定义 |
| 用户场景 | 梳理考纲、复习大纲 | 刷题时标注题目↔知识点的关联 |

## 五、视图切换方案

```edit
┌──────────────────────────────────────────────────────┐
│ [学科名]  [3D导图] [2D导图] [2D认知]         [返回]  │
├──────────────────────────────────────────────────────┤
│                                                      │
│              当前视图内容区                           │
│                                                      │
└──────────────────────────────────────────────────────┘
```

- 同一时刻只显示一个视图
- 切换时保持数据同步（共享 DataManager）
- 切换到认知地图时自动刷新数据（读取最新的思维导图节点 + 加载认知地图独立数据）

## 六、开发策略

1. **独立调试**：3个核心功能分别在独立项目中调试通过
2. **超级拼装**：各自跑通后整合到主工程
3. **数据兼容**：统一数据结构，确保3个视图读写同一份数据

## 七、快捷键方案

| 快捷键 | 功能 |
|--------|------|
| Ctrl+N | 新建节点（思维导图）/ 新建题目（认知地图） |
| Ctrl+Z | 撤销 |
| Ctrl+Y | 重做 |
| R | 刷新视图 |
| Delete | 删除选中节点/关系 |
| Escape | 取消选择 |
