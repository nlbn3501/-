# 3D认知地图 (3dtr) - 总览

> **⚠️ 已废弃**：2026-04-27 决定砍掉 3D 认知地图。认知地图的唯一视图改为 2D 认知地图（2dtr）。
> 理由：3D 认知地图的核心操作（标注关系）不如 2D 直观，且用户不需要第三个 3D 视图。
> 本目录文件仅供历史参考，不再维护。

## 一、功能定位

3D认知地图是2D认知地图的三维扩展，在2D认知地图的基础上根据节点层级分配Z轴深度，呈现知识关系的空间化视图。

**核心定义**：3D认知地图 = 2D认知地图 + Z轴深度映射

## 二、与2D认知地图的关系

| 维度 | 2D认知地图 | 3D认知地图 |
|------|-----------|-----------|
| 节点形态 | 矩形卡片 | 矩形卡片 + 3D深度 |
| 布局 | 力导向（2D平面） | 力导向（2D平面） + Z轴深度 |
| 连线 | 有向箭头（实线/虚线） | 有向箭头（实线/虚线） |
| 交互 | 不支持拖拽 | 不支持拖拽 |
| 编辑 | 只编辑关系 | 只编辑关系 |
| 相机 | 无 | 轨道相机（同3D思维导图） |

## 三、Z轴深度规则

节点在Z轴上的位置由其层级决定：

| 层级 | Z轴位置 | 说明 |
|------|---------|------|
| 根节点（depth=0） | Z = 0 | 最前层 |
| 第1层子节点 | Z = -2 | 第二层 |
| 第2层子节点 | Z = -4 | 第三层 |
| 第n层子节点 | Z = -n × 2 | 逐层后退 |

**参数**：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `z_layer_spacing` | 2.0 | 每层Z轴间距 |
| `z_direction` | -1.0 | Z轴方向（负值表示向屏幕内） |

## 四、模块组成

| 模块 | 职责 |
|------|------|
| CognitiveMap3D | 主控制器：相机、交互、关系编辑 |
| NodeRenderer3D | 3D矩形卡片渲染 |
| EdgeRenderer3D | 3D有向箭头渲染 |
| ForceLayout3D | 力导向布局（2D平面 + Z轴映射） |
| DataManager | 数据读写（共享） |

## 六、与思维导图的数据关系

- **节点来源**：认知地图的节点来自思维导图，不在认知地图中新建/删除节点
- **关系扩展**：认知地图在思维导图的parent关系基础上，添加5种额外关系
- **数据共享**：使用同一个DataManager实例，读写同一个JSON文件
- **编辑限制**：认知地图只能编辑 `relations` 字段，不能修改节点基本信息
