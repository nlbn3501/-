# 3D认知地图 - 节点交互（⚠️ 已废弃，见 overview.md）

## 一、选择系统

### 1.1 单选

| 触发 | 行为 |
|------|------|
| 左键点击节点 | 清除旧选择 → 选中该节点 → 高亮 |
| 左键点击空白 | 清除选择 |

### 1.2 多选

认知地图不支持多选（与思维导图不同，认知地图编辑的是关系而非节点）。

## 二、右键菜单

### 2.1 节点右键菜单

| ID | 菜单项 | 触发动作 |
|----|--------|----------|
| 1 | 查看详情 | `show_detail` |
| 2 | 定位到该节点 | `focus_node` |
| 3 | 在2D认知地图中打开 | `switch_view` |
| - | ---分隔线--- | - |
| 4 | 添加关系 | `add_relation` |
| 5 | 管理关系 | `manage_relations` |
| - | ---分隔线--- | - |
| 6 | 在思维导图中查看 | `switch_to_mindmap` |

### 2.2 空白右键菜单

| ID | 菜单项 | 触发动作 |
|----|--------|----------|
| 1 | 添加关系 | `add_relation` |
| - | ---分隔线--- | - |
| 2 | 刷新布局 | `refresh_layout` |
| 3 | 重置视图 | `reset_view` |

### 2.3 连线右键菜单

| ID | 菜单项 | 触发动作 |
|----|--------|----------|
| 1 | 修改关系类型 | `edit_relation` |
| 2 | 删除关系 | `delete_relation` |

## 三、详情卡片

双击节点弹出详情卡片，显示：

| 信息 | 来源 |
|------|------|
| 名称 | item.name |
| 描述 | item.description |
| 掌握程度 | item.mastery |
| 层级深度 | compute_depths()[index] |
| 父节点 | item.parent |
| 关联数量 | item.relations.size() |
| 关系列表 | item.relations（每条显示类型+目标） |
| 路径 | get_node_path(index) |

## 四、关系管理对话框

右键 → "管理关系" 时弹出，列出当前节点的所有关系：

```
┌─────────────────────────────────────┐
│  管理: {节点名称} 的关系              │
├─────────────────────────────────────┤
│  → 导数      [前置]  [删除]          │
│  → 连续      [关联]  [删除]          │
│  → 定积分    [不确定] [删除]          │
├─────────────────────────────────────┤
│            [添加新关系]              │
└─────────────────────────────────────┘
```

每条关系显示：
- 目标节点名称
- 关系类型（可点击修改）
- 删除按钮

## 五、正确行为验证点

1. 选择节点后高亮正确
2. 右键菜单项根据上下文正确显示
3. 连线右键菜单能正确识别点击的连线
4. 详情卡片信息完整准确
5. 关系管理对话框正确列出所有关系
6. 添加/删除/修改关系后视图正确更新
