## 一、布局算法

### 1.1 力导向布局（2D平面）

认知地图使用2D力导向布局确定节点的X/Y坐标，然后根据层级映射Z坐标。

**参数**：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `iterations` | 150 | 最大迭代次数 |
| `attraction` | 0.03 | 弹簧吸引力 |
| `repulsion` | 1.5 | 库仑排斥力 |
| `damping` | 0.85 | 速度衰减 |
| `center_attraction` | 0.01 | 向心力 |
| `ideal_spacing` | 3.0 | 理想节点间距 |

**力的计算**：

1. **排斥力**：每对节点之间，F = repulsion / distance²
2. **吸引力**：有关系的节点对之间，F = (distance - ideal_spacing) × attraction
3. **向心力**：所有节点向原点的力，F = position.length() × center_attraction

**收敛条件**：
- 总动能 < 0.001
- 达到最大迭代次数

### 1.2 Z轴深度映射

力导向布局完成后，根据节点深度设置Z坐标：

```gdscript
func apply_z_depth():
    var depths = data_manager.compute_depths()
    for i in data_manager.get_count():
        var z_pos = depths[i] * z_layer_spacing * z_direction
        set_node_z(i, z_pos)
```

### 1.3 布局优化

- 有关系的节点对在布局中应尽量靠近
- 确保连线不频繁穿越其他节点
- 不同层级（Z轴）的节点在X/Y平面上可以重叠（因为Z不同）

## 二、节点渲染

### 2.1 矩形卡片节点

使用3D面板渲染矩形卡片：

| 属性 | 值 |
|------|-----|
| 形状 | 矩形 |
| 尺寸 | 根据文本长度自适应，最小 2.0×1.0 |
| 圆角 | 0.1 |
| 背景色 | 白色 (1.0, 1.0, 1.0, 0.95) |
| 边框色 | 按掌握度 |

### 2.2 节点显示内容

**默认显示**：
- 节点名称（居中）

**双击详情卡片**：
- 名称
- 描述
- 掌握程度
- 关联数量
- 关系列表

### 2.3 掌握度颜色

| 掌握度 | 边框色 | 背景色 |
|--------|--------|--------|
| 0 未学习 | 灰色 (0.6, 0.6, 0.6) | 白色 |
| 1 学习中 | 橙黄 (1.0, 0.6, 0.1) | 浅黄 |
| 2 已掌握 | 绿色 (0.2, 0.85, 0.2) | 浅绿 |

### 2.4 选中高亮

- 选中节点边框变为亮黄色
- 发光效果

## 三、连线渲染

### 3.1 有向箭头连线

使用3D线条 + 箭头模型：

| 属性 | 值 |
|------|-----|
| 线宽 | 2.0 |
| 箭头大小 | 0.3 |
| 实线模式 | 连续线条 |
| 虚线模式 | dash pattern: 0.4, 0.2 |

### 3.2 连线路径

- 从源节点边缘到目标节点边缘
- 使用贝塞尔曲线平滑连接
- 箭头位于目标节点边缘

### 3.3 颜色编码

| 关系类型 | 颜色 |
|----------|------|
| hierarchy | 蓝色 #3399FF |
| prerequisite | 绿色 #33CC66 |
| association | 橙色 #FF9933 |
| application | 紫色 #9933CC |
| uncertain | 灰色 #999999 |

## 四、相机控制

与3D思维导图相同的轨道相机系统：

| 参数 | 默认值 |
|------|--------|
| 初始半径 | 20.0 |
| 初始theta | 0.0 |
| 初始phi | 0.5 |
| 平滑速度 | 12.0 |

**特殊行为**：
- 默认从斜上方俯视，能看到Z轴分层效果
- 聚焦节点时，相机移动到该节点所在Z层

## 五、环境设置

| 设置 | 值 |
|------|-----|
| 背景色 | (0.05, 0.05, 0.07) 深色 |
| 辉光效果 | 开启 |
| 网格辅助线 | 可选显示Z层平面 |

## 六、正确行为验证点

1. 力导向布局后连线不频繁穿越节点
2. Z轴分层清晰可见
3. 不同关系类型的颜色和线型正确
4. 箭头方向正确
5. 双击详情卡片信息完整
6. 相机可以自由旋转查看各层
