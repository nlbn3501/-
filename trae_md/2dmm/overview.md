# 2D思维导图 (2dmm) - 总览

## 一、功能定位

2D思维导图是知识点的XMind风格目录视图，以卡片节点和贝塞尔曲线连线呈现树形层级结构。支持节点选中、拖拽、Tab快捷键新增子节点/自由节点。

支持**星系系统**：根节点所在的星系（galaxy_id=0）按XMind树形展开；每个自由节点拥有独立的星系，子树整体拖拽。

## 二、模块组成

| 模块 | 文件 | 职责 |
|------|------|------|
| MindMap2D | MindMap2D.gd | 主控制器：布局、渲染、交互、缩放 |
| ContextMenuManager | ContextMenuManager.gd | 右键菜单（节点菜单、空白菜单、多选菜单） |
| DataManager | DataManager.gd | 数据读写（共享） |
| EditNodeDialog | EditNodeDialog.gd | 编辑节点对话框 |
| HistoryManager | HistoryManager.gd | 撤销/重做历史管理 |
| KeyboardShortcutManager | KeyboardShortcutManager.gd | 快捷键注册与匹配 |
| LayoutOptimizer | LayoutOptimizer.gd | 力导向布局优化、节点冲突检测与解决 |
| DebugLogger | DebugLogger.gd | 调试日志记录（控制台+文件双输出） |

## 四、与3D思维导图的关键差异

| 维度 | 3D思维导图 | 2D思维导图 |
|------|-----------|-----------|
| 布局 | 同心球面（自动），多星系 | XMind左右展开 + 手动拖拽 |
| 拖拽 | 禁用 | 允许（子树整体拖拽/吸附/拖出） |
| 节点形态 | 球体 | 卡片（白框透明填充白字） |
| 连线 | TubeTrailMesh曲线 | Line2D贝塞尔曲线 |
| 坐标系 | 3D (position) | 2D (pos2d) |
| 缩放 | 相机半径 | container.scale + ScrollContainer |
| 选中/悬停 | 辉光效果 | 边框颜色变化 |
| 快捷键 | Tab（新增子节点） | Tab（子节点/自由节点）+ F2/Ctrl+S/L/O/Space |
| 星系 | 星系通过同心球面布局 + 轨道球分布 | 星系通过树形结构 + 子树整体拖拽管理 |
| 节点放置 | 对话框指定位置 | 放置模式（鼠标跟随+点击确认） |
