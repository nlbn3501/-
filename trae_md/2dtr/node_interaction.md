# 2D认知地图 — 节点交互

## 一、选择与打开

| 触发 | 目标 | 行为 |
|------|------|------|
| 单击 | 题目节点 | 选中，高亮显示 |
| 双击 | 题目节点 | 打开右侧 ProblemPanel 侧面板 |
| 单击 | 知识点节点 | 选中，高亮该节点 + 所有关联题目 |
| 右键 | 任意节点 | 显示对应类型的上下文菜单 |
| 单击空白 | 画布 | 取消选择 |
| 拖拽 | 任意节点 | 移动节点位置，自动 pinned |
| 双击 | 已 pinned 节点 | 解除 pinned，恢复受力 |

---

## 二、右键菜单

### 2.1 空白处右键

| 菜单项 | 触发动作 |
|--------|----------|
| 新建题目 | 弹出新建题目窗口 |
| 连线 | 进入连线模式（选择关系类型后依次点击题目和知识点节点） |
| 搜索知识点 | 弹出搜索框，输入名称拉取未显示的思维导图节点到画布 |
| 刷新布局 | 重新跑力导向（pinned 节点不动） |
| 重置视图 | 恢复默认缩放和滚动位置 |

### 2.2 题目节点右键

| 菜单项 | 触发动作 |
|--------|----------|
| 编辑题目 | 打开右侧 ProblemPanel 侧面板 |
| 管理关系 | 直接打开侧面板的关系管理区 |
| 解除固定 | 如果节点已 pinned，解除固定 |
| 删除题目 | 删除题目 + 所有关联关系（需确认） |

### 2.3 知识点节点右键

| 菜单项 | 触发动作 |
|--------|----------|
| 在思维导图中查看 | 切换到思维导图并聚焦该节点 |
| 显示题目列表 | 弹出浮窗列出所有关联该知识点的题目 |
| 添加到画布 | 如果有未显示的关联知识点，可手动拉取 |

### 2.4 连线右键

| 菜单项 | 触发动作 |
|--------|----------|
| 修改关系类型 | 弹出关系类型选择下拉框（用到/可替换/前置/延伸/自定义） |
| 删除关系 | 删除该条关系（需确认） |

## 三、新建题目流程

### 方式A：弹窗创建（推荐集中建题时使用）

```
右键 → "新建题目"

弹出窗口：
┌──────────────────────────────────┐
│  新建题目                         │
│  ───────────────────────────────  │
│  标题: [输入...]                   │
│  题型: [计算题 ▼]                  │
│  难度: [★★★★★] 点击选择星级       │
│  来源: [输入...]                  │
│  ───────────────────────────────  │
│  图片:                             │
│  [+ 添加图片]                      │
│  ───────────────────────────────  │
│  关联知识点 (可选，可在之后补充):    │
│  搜索: [拉格朗日......]            │
│  ┌─────────────────────┐         │
│  │ 拉格朗日乘数法 [用到 ▼]        │
│  │ 黑塞矩阵     [用到 ▼]          │
│  └─────────────────────┘         │
│  [+ 添加知识点]                    │
│  ───────────────────────────────  │
│  注释: [输入...]                  │
│  ───────────────────────────────  │
│  [保存]  [取消]                   │
└──────────────────────────────────┘
```

**搜索知识点**：输入文字 → 从思维导图中按节点名称模糊匹配 → 选择后自动拉取该节点到画布（如果尚未加载）。

### 方式B：画布拖拽连线（推荐边刷题边标注时使用）

```
① 右键 → "连线"
② 选择关系类型（用到/可替换/前置/延伸/自定义）
③ 鼠标变成十字线
④ 点击题目节点（或已选中题目节点）→ 虚影一端固定在题目，一端跟随鼠标
⑤ 点击目标知识点节点 → 关系建立
⑥ 点击空白 → 取消连线
```

连线建立后，如果目标知识点尚未出现在画布上，自动从思维导图加载显示。

## 四、题目编辑

### 4.1 侧面板编辑

双击题目节点 → 右侧滑出 ProblemPanel 侧面板，可编辑：
- 标题、题型、难度、来源
- 图片管理（添加/删除，支持拖放添加和文件选择）
- 注释
- 关系管理（添加/删除/修改类型）

### 4.2 关系管理（在侧面板中）

```
关联知识点:
  极限定义      [用到 ▼]  [🗙]
  等价无穷小    [用到 ▼]  [🗙]
  [+ 添加知识点]

点击 [+ 添加知识点] → 弹出搜索框 → 搜索思维导图中的节点 → 选择 → 设定关系类型 → 确认
```

## 五、知识点按需加载

画布不预加载思维导图的所有节点。加载规则：

| 场景 | 行为 |
|------|------|
| 关系引用 | 题目建立关系时，若目标知识点不在画布上 → 自动加载显示 |
| 搜索拉取 | 右键 → "搜索知识点" → 手动搜索并拉取 |
| 全量加载 | 不提供全量加载（设计上不必要） |

## 六、数据同步（自动刷新）

切换到认知地图时自动执行：
1. `CognitiveMapDataManager.refresh()` 重新读取 `mindmap_nodes.json`
2. 对比旧数据：
   - 删除的知识点 → 从 `relations.json` 中清理所有引用该知识点的关系
   - 改名的知识点 → 更新 `relations.json` 中所有 `target` 字段
   - 新增的知识点 → 无影响（不自动加载到画布）
3. 重新加载 `problems.json`、`relations.json`、`layout.json`
4. 重跑力导向（恢复 pinned 位置和组展开状态）

额外提供手动刷新按钮用于应急。

> **注意**：`refresh()` 的时序为 `_load_mindmap_nodes()` → `_validate_relations()` → `load_all()`。`_validate_relations()` 基于最新加载的 mindmap 节点列表来判断旧 relations 中的 target 是否仍然有效。如果 mindmap_nodes.json 尚未保存（用户还在编辑），此操作不会误删关系，因为思维导图的保存发生在切换 Tab 之前。

## 七、快捷键

| 快捷键 | 功能 |
|--------|------|
| Ctrl+N | 新建题目 |
| Ctrl+S | 保存所有数据 |
| R | 刷新布局 |
| Delete | 删除选中节点/关系 |
| Escape | 取消选中/退出连线模式 |
| Ctrl+F | 聚焦搜索框 |

---

## 八、正确行为验证点

1. 单击选中知识点时，关联题目同步高亮
2. 双击题目/组内题目项 → 打开 ProblemPanel
3. 拖拽连线虚影正常跟随鼠标
4. 连线时目标节点不存在于画布上 → 自动加载
5. 新建题目后保存到 problems.json
6. 添加关系后保存到 relations.json
7. 修改关系类型后连线颜色正确更新
8. 切换到认知地图时自动刷新数据
9. 思维导图删除知识点 → 切回认知地图时自动清理引用
10. 思维导图修改知识点名称 → 切回认知地图时自动更新引用
