# 2D认知地图 (2dtr) — 总览

## 一、功能定位

2D认知地图是用户的**解题经验编织工具**，核心任务是帮助用户在刷题过程中建立「题目↔知识点」的关联网络。

**一句话本质**：思维导图管理"有什么知识点"，认知地图管理"哪些题用到了这些知识点以及它们之间什么关系"。

**架构特点**：采用两层结构——主视图显示题目卡片网格，双击题目进入该题目的独立关系画布。

---

## 二、核心模型

### 2.1 题目节点

| 属性 | 说明 |
|------|------|
| 来源 | 用户在认知地图中创建 |
| 可编辑 | ✅ 编辑标题/题型/难度/图片/注释 |
| 显示 | 标题 + 难度星 + 题型标签 + 关联知识点标签 |

### 2.2 知识点节点

| 属性 | 说明 |
|------|------|
| 来源 | 从思维导图只读引用 |
| 可编辑 | ❌ 不可编辑内容 |
| 显示 | 仅在独立关系画布中显示，名称 + 关系类型颜色 |

### 2.3 关系

关系存储为**有向边**，方向为**题目→知识点**。存储在 `relations.json` 中（详见 `relationship_system.md`）。

5种关系类型：用到、可替换、前置、延伸、自定义。

### 2.4 数据独立性

- 认知地图数据通过 `{subject}_cog.json` 存储
- 知识点节点仅通过名称字符串引用思维导图中的节点
- 思维导图删除/改名知识点时，切换到认知地图时自动同步

## 三、架构设计

### 3.1 两层结构

```
主视图（题目卡片网格）
├── 题目卡片1（标题+难度+题型+关联知识点标签）
├── 题目卡片2
├── 题目卡片3
└── ...
    双击 → 进入独立关系画布

独立关系画布（ProblemCanvas）
├── 顶部栏：← 返回 | 题目标题 | ★★★ | 计算题
├── 上区：[用到的知识点] [延伸的知识点] ...
├── 中区：[题目卡片]（不可移动）
├── 下区：[前置知识] ...
└── 右键空白：添加关联知识点 | 添加关系线
```

### 3.2 主视图（CognitiveMap2D）

- 题目卡片网格布局（2列自动换行）
- 卡片显示：标题、难度星标、题型标签、关联知识点彩色标签
- 双击卡片 → 打开编辑对话框 → "进入关系画布"按钮
- 右键菜单：新建题目、添加关联知识点、添加关系线、自动布局、刷新、重置视图
- 选中节点时高亮相关连线

### 3.3 独立关系画布（ProblemCanvas）

每个题目有独立的关系画布，三行布局：

- **上区**：用到/可替换/延伸的知识点节点
- **中区**：题目卡片（固定位置）
- **下区**：前置知识节点

连线从上区/下区指向中区，使用贝塞尔曲线，颜色按关系类型区分。

## 四、模块组成

| 模块 | 文件 | 职责 |
|------|------|------|
| CognitiveMap2D | `CognitiveMap2D.gd` | 主视图：题目卡片网格、力导向布局、连线绘制、选中高亮 |
| CognitiveMapDataManager | `CognitiveMapDataManager.gd` | 数据读写：problems + relations + mindmap引用校验 |
| ProblemCanvas | `ProblemCanvas.gd` | 题目独立关系画布：三行布局、连线、右键添加/删除关系 |
| ContextMenuManager | `ContextMenuManager.gd` | 右键菜单管理（认知地图专用菜单项） |
| HistoryManager | `HistoryManager.gd` | 历史记录：撤销/重做 |

## 六、交互流程

### 打开认知地图（自动加载）
```
① 切换到2D认知Tab
② _sync_cog_data_from_2dmm() → 同步思维导图知识点
③ 加载 problems + relations
④ 渲染题目卡片网格
```

### 刷题时典型操作
```
遇到一道新题 → 右键 → "新建题目" → 填标题/题型/难度 → 保存
            → 双击题目 → 编辑对话框 → "进入关系画布"
            → 右键空白 → "添加关联知识点" → 搜索 → 选择类型 → 确认
            → 关系建立 → 画布自动显示该知识点节点 + 连线
            → 返回主视图
```

### 复习时典型操作
```
主视图中浏览题目卡片
→ 看到关联知识点标签，了解每题涉及的知识点
→ 双击题目 → 进入关系画布
→ 查看前置知识和用到的知识点的完整关系图
→ 右键添加/删除/修改关系
→ 返回继续浏览
```

## 七、数据同步

| 操作 | 触发视图 | 同步行为 |
|------|----------|----------|
| 新建/编辑/删除知识点 | 思维导图 | DataManager.save_data() |
| 知识点改名 | 思维导图 | 保存后，切换到认知地图时自动更新关系中的 target 引用 |
| 删除知识点 | 思维导图 | 保存后，切换到认知地图时自动清理引用该知识点的关系 |
| 新增/修改/删除题目 | 认知地图 | CognitiveMapDataManager 保存 |
| 新增/修改/删除关系 | 认知地图 | CognitiveMapDataManager 保存 |
| 切换到认知地图 | Tab切换 | 自动调用 _sync_cog_data_from_2dmm() |
