# 2D认知地图 — 关系系统

## 一、关系类型定义

所有关系方向为 **题目→知识点**。

| 类型值 | 中文名 | 连线样式 | 颜色 | 说明 |
|--------|--------|----------|------|------|
| `用到` | 用到 | 实线箭头 | #3399FF 蓝色 | 这道题用到了该知识点（最常用） |
| `可替换` | 可替换 | 虚线箭头（dash 8,4） | #FF9933 橙色 | 该知识点/方法可替换原方案 |
| `前置` | 前置知识 | 实线箭头 | #33CC66 绿色 | 解题前需要掌握的前置知识点 |
| `延伸` | 延伸 | 点线箭头（dash 2,4） | #9933CC 紫色 | 该题可延伸到的相关知识点/变式 |
| `自定义` | 自定义 | 实线箭头 | #999999 灰色 | 用户自定义关系类型，可改标签文字 |

## 二、数据存储

关系存储在独立的 `relations.json` 文件中，每条关系一条记录：

```json
[
    {
        "id": "rel_001",
        "problem_id": "prob_001",
        "target": "极限定义",
        "type": "用到",
        "label": "核心方法"
    }
]
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | String | 唯一标识符，`rel_{三位数}` 自动递增 |
| `problem_id` | String | 关联的题目ID，引用 problems.json |
| `target` | String | 知识点名称，引用 mindmap_nodes.json 中的 name 字段 |
| `type` | String | 关系类型（用到/可替换/前置/延伸/自定义） |
| `label` | String | 自定义备注（可选） |

**关系不在知识点节点上存储，不在思维导图数据中存储。**

## 三、关系可视化

### 3.1 连线渲染

| 属性 | 值 |
|------|-----|
| 起点 | 题目节点边缘（朝向知识点方向） |
| 终点 | 知识点节点边缘（朝向题目方向） |
| 路径 | 直线段（两点间） |
| 箭头 | 三角形箭头，在终点处绘制，大小 8px |
| 方向 | 题目 → 知识点（箭头从题目指向知识点） |
| 线宽 | 2.0 |
| 标签 | 关系类型中文名，默认隐藏，鼠标悬停时在连线中点显示 |

### 3.2 颜色与线型编码

| 类型 | 颜色 | 线型 |
|------|------|------|
| 用到 | #3399FF | 实线 |
| 可替换 | #FF9933 | 虚线（dash_pattern = [8, 4]） |
| 前置 | #33CC66 | 实线 |
| 延伸 | #9933CC | 点线（dash_pattern = [2, 4]） |
| 自定义 | #999999 | 实线 |

### 3.3 虚线/点线处理

使用 `Line2D` 的 `dash_length` 属性实现虚线效果：

| 线型 | 参数 |
|------|------|
| 实线 | `dash_length = -1`（默认，不启用虚线） |
| 虚线（可替换） | `dash_length = 8`，点间空隙 4px |
| 点线（延伸） | `dash_length = 2`，点间空隙 4px |

## 四、关系编辑

### 4.1 添加关系

**方式一（弹窗）**：
- 新建题目时在弹窗中直接添加关系
- 编辑题目时在侧面板点击"+ 添加知识点"

**方式二（画布拖拽）**：
- 右键 → "连线" → 选择关系类型 → 依次点击题目和知识点节点

**验证规则**：
1. 题目和知识点不能相同（类型不同，不会出现）
2. 同一题目和同一知识点之间不允许重复的相同类型关系
3. 目标知识点必须在思维导图中存在（`CognitiveMapDataManager.refresh()` 时校验）

### 4.2 删除关系

| 触发方式 | 行为 |
|----------|------|
| 侧面板关系管理的 [🗙] 按钮 | 删除该条关系 |
| 画布右键点击连线 → "删除关系" | 删除该条关系 |

### 4.3 修改关系类型

| 触发方式 | 行为 |
|----------|------|
| 侧面板关系管理中的下拉框 | 切换类型 |
| 画布右键点击连线 → "修改关系类型" | 弹出类型选择，切换 |

## 五、思维导图数据联动

### 5.1 知识点改名时

```gdscript
# CognitiveMapDataManager.rename_knowledge_target(old_name, new_name)
# 遍历 relations.json 中所有 target == old_name 的记录
# 更新为 new_name
```

### 5.2 知识点删除时

```gdscript
# CognitiveMapDataManager.cleanup_relations_for_knowledge(name)
# 遍历 relations.json 中所有 target == name 的记录
# 删除这些关系（题目保留，仅关系被清理）
```

### 5.3 题目删除时

```gdscript
# CognitiveMapDataManager.remove_problem(problem_id)
# 删除题目本身 + 所有 problem_id 匹配的关系
```

## 六、正确行为验证点

1. 5种关系类型颜色和线型正确区分
2. 箭头方向正确（题目→知识点，起点在题目边缘，终点在知识点边缘）
3. 关系标签在悬停时显示
4. 添加/删除/修改关系后数据正确保存到 relations.json
5. 删除题目时关联关系同时清理
6. 思维导图删知识点时关联关系清理（题目不删）
7. 思维导图改知识点名时关联关系自动更新 target
8. 同一对节点不重复同类型关系
