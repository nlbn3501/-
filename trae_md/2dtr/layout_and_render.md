# 2D认知地图 — 布局与渲染

## 一、力导向布局

### 1.1 核心思路

画布上所有**独立节点**（知识点节点 + 非合并的题目节点 + 组节点）共同参与力导向计算：

- **排斥力**：所有节点之间相互排斥，避免重叠
- **吸引力**：有关系连接的节点对被吸引（题目/组 → 它关联的所有知识点）
- **向心力**：所有节点向画布中心方向轻微的拉力，防止散出画布

**题目节点的位置** = 它关联的所有知识点的几何中心 + 受力平衡结果。关联了 3 个知识点的题自动拉到 3 个节点的中间位置。

**组节点**在力导向中作为一个整体参与，代表键为组内第一个题目的 ID。

### 1.2 力学参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `repulsion` | 800.0 | 排斥力系数 |
| `attraction` | 0.005 | 吸引力系数（有关系节点对） |
| `center_gravity` | 0.001 | 向心力系数 |
| `ideal_distance` | 250.0 | 理想节点间距（像素） |
| `damping` | 0.92 | 速度衰减系数 |
| `pinned_threshold_velocity` | 0.5 | 当速度低于此值时认为布局稳定 |
| `max_iterations` | 300 | 最大迭代次数 |
| `max_force` | 600.0 | 单步最大力 |

### 1.3 力的计算

```
排斥力（所有节点对）:
    F_repulsion = repulsion / distance
    方向: node_i → node_j
    上限: max_force

吸引力（有关系的节点对）:
    F_attraction = (distance - ideal_distance) × attraction
    方向: node_j → node_i（拉近）
    上限: max_force

向心力:
    F_center = (center - position).normalized() × distance_to_center × center_gravity
    上限: max_force × 0.5
```

### 1.4 布局稳定条件

- 所有节点的速度 < `pinned_threshold_velocity`（0.5）
- 或达到最大迭代次数（300次）

### 1.5 初始位置

- 知识点节点：从 layout.json 中的 pinned 位置恢复；无 pinned 记录的随机分布在画布中央区域
- 题目节点：其关联知识节点的几何中心 + 小偏移
- 组节点：同题目节点逻辑（以组内第一个题目为代表）

## 二、Pinning 系统

### 2.1 规则

| 操作 | 行为 |
|------|------|
| 用户拖动节点 | 节点 pinned = true，不再参与受力，停留在拖动位置 |
| 双击已 pinned 节点 | 解除 pinned，节点恢复受力，力导向重新调整位置 |
| 刷新布局 | 所有非 pinned 节点重新受力排布，pinned 节点不动 |
| 保存 | 只有 pinned 的节点位置记录到 layout.json |

### 2.2 视觉反馈

- pinned 节点右下角显示 🔒 小锁图标
- 节点边框变为用户指定的高亮色

### 2.3 保存策略

布局操作后不立即保存全部数据，只在以下时机保存 layout.json：
- 用户停止拖动后 1 秒（debounce）
- 关闭/切换视图时

## 三、题目分组合并

### 3.1 合并条件

拥有**完全相同的关系集合**（相同的 `target:type` 对集合）的题目自动合并为一个组节点。

**签名生成规则**：
1. 对每道题，收集其所有关系的 `"target:type"` 字符串
2. 排序后用 `"|"` 拼接，得到签名
3. **没有关系的题目**，签名设为 `"single_<prob_id>"`（确保唯一，不参与合并）

示例：

| 题 | 关联知识点+关系 | 签名 | 合并？ |
|----|----------------|------|--------|
| 题1 | 极限定义(用到), 等价无穷小(用到) | `极限定义:用到|等价无穷小:用到` | ✅ 同组 |
| 题2 | 等价无穷小(用到), 极限定义(用到) | `极限定义:用到|等价无穷小:用到` | ✅ 同组 |
| 题3 | 极限定义(用到), 夹逼准则(用到) | `夹逼准则:用到|极限定义:用到` | ❌ 不同组 |
| 题4 | （无关系） | `single_prob_004` | ❌ 独立 |
| 题5 | （无关系） | `single_prob_005` | ❌ 独立 |

### 3.2 组节点渲染

```
默认状态（折叠）:
┌──────────────────────┐
│  🔁 同类题 ×3         │  ← 组标题
│  ★★~★★★★            │  ← 难度范围
│  展开 ↘               │  ← 点击展开
└──────────────────────┘

展开后:
┌──────────────────────┐
│  🔁 同类题 ×3         │
│  折叠 ↗               │  ← 点击折叠
├──────────────────────┤
│ ┌──────────────────┐ │
│ │ ① 求极限 sinx/x ★★★ │ │  ← 可交互项
│ └──────────────────┘ │    单击=选中
│ ┌──────────────────┐ │    双击=打开侧面板
│ │ ② 求极限 tanx/x ★★  │ │    右键=上下文菜单
│ └──────────────────┘ │
│ ┌──────────────────┐ │
│ │ ③ 求极限 arcsinx/x ★│ │
│ └──────────────────┘ │
└──────────────────────┘
```

### 3.3 展开/折叠交互

| 触发 | 条件 | 行为 |
|------|------|------|
| 单击 "展开 ↘" | 组处于折叠状态 | 展开组，显示子题目列表 |
| 单击 "折叠 ↗" | 组处于展开状态 | 折叠组，隐藏子题目列表 |
| 单击子题目项 | 组处于展开状态 | 选中该题目，高亮 |
| 双击子题目项 | 组处于展开状态 | 打开该题目的 ProblemPanel 侧面板 |
| 右键子题目项 | 组处于展开状态 | 显示该题目的上下文菜单 |
| 拖拽组面板 | 任意状态 | 移动整个组的位置（pinned） |

### 3.4 组节点与力导向的交互

- 合并组作为一个整体参与力导向（力作用在组节点中心，代表键为组内第一个题目 ID）
- 展开时，子题目不参与力导向计算，不影响其他节点位置
- 折叠/展开状态记录在 layout.json 的 `expanded_groups` 字段
- 组节点的 pinned 状态和位置记录在 layout.json 的 `node_positions` 字段中（键为组内第一个题目 ID）

## 四、缩放层级

缩放通过滚轮控制，范围 0.25~3.0。

| 级别 | 缩放值 | 知识点显示 | 题目/组显示 |
|------|--------|-----------|------------|
| 概览 | 0.25~0.5 | 小色块 + 名称（无路径、无角标） | 小色块 + 难度星（无标题） |
| 中等 | 0.5~1.5 | 卡片（名称 + 路径 + 题数角标） | 紧凑卡片（标题 + 难度 + 题型标签） |
| 详细 | 1.5~3.0 | 完整卡片 + 字号放大 | 完整卡片 + 注释摘要 + 图片数 |

缩放级别影响 `zoom_scale` 变量，所有渲染逻辑通过 `zoom_scale` 动态调整字号、间距、边距。

## 五、节点渲染

### 5.1 知识点节点

```
┌─────────────────┐
│  极限定义          │  ← 浅灰色底，圆角小矩形
│  函数篇 > 极限     │  ← 小字面包屑路径
│  ◇ 3题           │  ← 关联题数角标
└─────────────────┘
```

| 属性 | 值 |
|------|-----|
| 背景色 | Color(0.85, 0.85, 0.85, 0.3) |
| 圆角 | 8px |
| 边框 | 1px, Color(0.6, 0.6, 0.6) |
| 标题字号 | 14，白色 |
| 路径字号 | 10，灰色 |
| 关联题数 | 右下角圆形角标 |

### 5.2 题目节点

```
┌──────────────────────┐
│  求极限 sinx/x        │  ← 白色卡，稍大
│  ★★★  计算题     │  ← 难度+题型标签
│  📷 ×2               │  ← 图片数
│  💬 核心是配凑..      │  ← 注释摘要（前10字）
└──────────────────────┘
```

卡片颜色按题型区分:

| 题型 | 色调 |
|------|------|
| 计算题 | 蓝色调 |
| 证明题 | 绿色调 |
| 选择题 | 橙色调 |
| 填空题 | 紫色调 |
| 其他 | 灰色调 |

### 5.3 关系连线

使用 `Line2D` 绘制有向箭头：

| 属性 | 值 |
|------|-----|
| 起点 | 题目节点边缘（朝向知识点方向） |
| 终点 | 知识点节点边缘（朝向题目方向） |
| 箭头 | 末端三角形，8px，方向：题目→知识点 |
| 线宽 | 2.0 |
| 标签 | 关系类型中文名，鼠标悬停时在连线中点显示 |

颜色和线型按关系类型区分：

| 类型 | 颜色 | 线型 |
|------|------|------|
| 用到 | #3399FF 蓝色 | 实线 |
| 可替换 | #FF9933 橙色 | 虚线（dash 8,4） |
| 前置 | #33CC66 绿色 | 实线 |
| 延伸 | #9933CC 紫色 | 点线（dash 2,4） |
| 自定义 | #999999 灰色 | 实线 |

## 六、筛选栏（顶部）

```
┌──────────────────────────────────────────────────────────┐
│ [🔍 搜索题目] [章节 ▼] [题型 ▼] [难度 ▼] [来源 ▼] [🔄] │
└──────────────────────────────────────────────────────────┘
```

筛选逻辑：
- 搜索：按 `title` 字段模糊匹配
- 章节：显示此章节下被引用过且本画布上有题的知识点
- 题型：单选或全选
- 难度：单选或全选
- 来源：按 `source` 字段过滤
- 刷新：重新加载所有数据 + 重跑力导向

筛选仅影响画布上节点的显示/隐藏，不影响数据存储。

## 七、正确行为验证点

1. 力导向布局后节点不重叠
2. 题目节点被关系线拉向关联知识点的几何中心方向
3. 拖动节点后正确 pinned，不再移动
4. 双击解除 pinned 后恢复受力
5. 无关系题目独立显示，同类题自动合并为组节点
6. 组节点展开后子题目可单击选中、双击打开侧面板、右键菜单
7. 缩放各级别显示内容正确
8. 侧面板图片纵向排列，点击全屏正常
9. 筛选后画布节点正确显示/隐藏
10. 关系连线箭头方向正确（题目→知识点）
11. 五种关系类型颜色和线型正确区分
